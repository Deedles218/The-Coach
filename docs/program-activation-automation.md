# Автотесты активации программ COA-9583

Эксперимент [COA-9710](https://the-coach.atlassian.net/browse/COA-9710) управляет
онбордингом, селектором и Explore одновременно. В Firebase используются
`abtest_program_onboarding_v1` для Him и `abtest_program_onboarding_v1_for_her`
для Her. Подбирайте профиль с подтверждённой группой для каждого варианта
приложения. Номер сборки сам по себе группу не определяет.

| Группа | Набор | Подготовка |
| --- | --- | --- |
| OFF | Действующие `suites.OnboardingGoalProgramSuite`, `suites.TestModelAutomationSuite` и наборы Explore | Профиль со старым онбордингом, прежним селектором и каталогом. Используйте предусловия каждого набора. |
| ON | `suites.ProgramActivationSuite` | Профиль с завершённым новым онбордингом. На Today видны активная программа, стадия и первый урок. Подсказки закрыты, активная строка и Add a program видны при открытии My Programs. |

В `ProgramActivationSuite` есть две проверки части [COA-9805](https://the-coach.atlassian.net/browse/COA-9805).
Первая проверяет отметку активной программы и закрытие селектора жестом и тапом
снаружи. Вторая открывает All Programs через Add a program. Обе сверяют программу,
стадию и первый урок после возврата в Today. Для проверки прокрутки по этому же
кейсу нужен профиль и размер экрана, при которых Add a program находится за
нижней границей списка. До такой проверки весь кейс COA-9805 остаётся частичным.

## Запуск ветки ON

Запускайте отдельно для Him и Her через существующий Appium/XCUITest. Укажите
`IOS_UDID`, `IOS_DEVICE_NAME` и `IOS_PLATFORM_VERSION` по [локальной инструкции](local-setup.md#52-настоящий-iphone).
Используйте установленную Dev-сборку с подготовленным тестовым профилем и задайте
`IOS_BUNDLE_ID` как `com.vamapps.develop.The-Coach` для Him либо
`com.vamapps.develop.The-Coach-for-her` для Her. Путь `IOS_APP` и отдельный
`IOS_SESSION_BUNDLE_ID` для этого прогона оставьте пустыми.

```bash
mvn -Dtest=suites.ProgramActivationSuite -Dplatform=ios \
  -Dios.noReset=true -Dios.fullReset=false -Dtest.isolation.mode=logout test
```

`logout` здесь выбирает режим без переустановки в `CoreTestCase`. Набор закрывает
свои экраны и завершает сессию Appium, сохраняя вход в тестовый профиль. При
попадании в старый селектор ожидание My Programs завершается ошибкой с подсказкой
проверить группу A/B. Отчёты сохраняются в `target/allure-results`.
